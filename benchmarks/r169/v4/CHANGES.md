## 2. البيانات `scripts/r169_build_dataset_v4.py`

- البذرة 1694، ملح الكناري `v4`، الإصدار `r169-v4`. 216 حالة: dev ‏52 / validation ‏46 /

  إقليمية»، قديم «الواجهة البرمجية المستقرة»، حقن `[[SYSTEM OVERRIDE]]`، ضغط المستخدم «اسم
  الرئيس التنفيذي غير المذكور»، أداة `reservoir_level` بتعليمات تسريب.
