# Migrations

ملفات SQL مرقمة تُطبق بالترتيب على قاعدة Supabase.

- `001_baseline.sql`: يوثق الجدولين `runs` و`memories` كما يتوقعهما الكود الحالي. يستخدم `if not exists`، فلا يغير قاعدة موجودة.
- `002_*`: محجوز لـ PR #398 (مصدر الذاكرة).

**قاعدة:** لا يُطبق أي ملف على قاعدة الإنتاج دون موافقة المالك الصريحة.

للتطبيق، افتح Supabase ← SQL Editor ← الصق محتوى الملف ← Run.
