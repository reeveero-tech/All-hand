# رؤية المنتج: All-hand

- **الحالة:** `designed`.
- **تاريخ الكتابة:** 2026-11-25.

## الفكرة في جملة

All-hand منصة عربية أولًا ومفتوحة المصدر. تكتب فيها النتيجة التي تريدها، فيخطط المنسق وينفذ عبر وكلاء متخصصين وأدوات حقيقية. كل ناتج يمر على مدقق مستقل، والمنصة تسلّمك مخرجات قابلة للاستخدام مع سجل صادق لما حدث وما فشل.

## لمن؟

| المستخدم | حاجته | ما يجب أن يحصل عليه |
|---|---|---|
| صاحب عمل صغير (عربي) | بحث سوق، خطط، محتوى، تحليل ملفات | تقرير موثق بمصادر، دون أن يتعلم أدوات تقنية |
| محلل أو باحث | جمع معلومات عن عناصر كثيرة ومقارنتها | جداول ومقارنات تُجمع بالتوازي، مع مصادر لكل خلية |
| مطوّر | فحص مستودع، كتابة كود، فتح PR | عمل على GitHub بموافقته قبل أي إجراء مؤثر |
| فريق | مشاريع مشتركة وذاكرة ومهارات موحدة | صلاحيات وأدوار وسجل تدقيق |

## المبادئ (غير قابلة للتفاوض)

1. **الصدق قبل المظهر.** لا نعرض زرًا لا يعمل، ولا نسمي الخطأ نجاحًا، ولا ندعي اكتمال شيء لم يُختبر.
2. **المستخدم يملك بياناته.** العزل حسب المالك في كل مسار، ومسح الذاكرة فعلي، والأسرار لا تُعرض أبدًا.
3. **الموافقة قبل الأثر.** كل إجراء خارجي مؤثر (إرسال، نشر، دمج، دفع، حذف) يحتاج موافقة صريحة على نطاقه المحدد.
4. **التكلفة مرئية.** يُعرض الاستهلاك لكل مهمة، ويبقى خيار مجاني يعمل.
5. **العربية أولًا.** RTL صحيح ونصوص طبيعية، والإنجليزية لغة ثانية كاملة.
6. **حالة دائمة.** المهمة لا تضيع عند إعادة تشغيل الخادم (هدف المرحلة 2).
