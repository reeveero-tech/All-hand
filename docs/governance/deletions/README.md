# قوائم الحذف المعتمد (R-203، D-152)

> بوابة عدم الحذف (`scripts/check_no_delete.py`، R-152) ترفض أي حذف أو نقل أو إعادة تسمية لملف متعقب **إلا** إن كان المسار في قائمة هنا **مدموجة مسبقًا** في `main`.

## القواعد (مفروضة آليًا)

1. القائمة ملف `DEL-NNN.list`، مسار واحد دقيق في كل سطر (لا أنماط ولا مجلدات)، والأسطر التي تبدأ بـ`#` تعليقات.
2. سطر `# decision: D-NNN` إلزامي، وقسم القرار في `DECISIONS.md` يجب أن يذكر اسم ملف القائمة.
3. البوابة تقرأ القوائم من **نقطة التفرع** (merge-base) بين الفرع و`main`، لا من الفرع نفسه: PR لا تستطيع أن تأذن لنفسها بالحذف (اعتراض D-064 على ملف الاستثناءات).
4. **دفعتان منفصلتان**: دفعة 1 تضيف القائمة وقرارها (بلا حذف)؛ دفعة 2 تحذف بعد دمج الأولى. PR تحذف ملفات لا يجوز أن تضيف أو تعدل قائمة.
5. القائمة المدموجة **لا تُعدَّل ولا تُحذف**؛ أي توسيع = قائمة جديدة بقرار جديد.
6. القائمة الجديدة تُفحص في PR إضافتها: الصيغة، القرار موجود ويذكرها، وكل مسار متعقب فعلًا.
7. لا تجاوز عبر labels أو نص PR أو متغيرات بيئة.
