# P0 — الحوكمة والتكامل الذري (R-151 إلى R-154)

## R-151 — إدخال خارطة الطريق إلى المستودع
**الأولوية:** P0 / مانعة. **النطاق:** توثيق فقط.  
**العمل:** أضف ملفات الخطة إلى `docs/governance/roadmaps/revival-scale/`، واربِطها من `docs/governance/ROADMAP.md`. حدّث PROJECT_STATE وCHANGELOG في PR نفسها، مع دليل `docs/audit/`.  
**القبول:** لا تغيير في الكود التشغيلي؛ لا ملفات محذوفة/منقولة؛ كل الروابط النسبية تعمل؛ مهام R-151..R-184 مسجلة كخطة؛ كل الفحوص المطلوبة تمر على SHA الدمج.

## R-152 — بوابة عدم الحذف
**العمل:** أضف تحققًا للـdiff يمنع حذف/rename tracked files ضمن البرنامج، أو يرفض PR إذا لم يوجد تفويض موثق خاص من المالك. حتى التفويض، القاعدة صفر حذف/rename/move.  
**القبول:** اختبارات بوابة إيجابية وسلبية، وأدلة؛ لا تضع قواعد تتجاوز حماية الفرع أو تعتمد على نص PR غير قابل للتحقق.

## R-153 — الذرية في كل دفعة
**العمل:** طبّق قائمة تحقق آلية/مساعدة تفرض تحديث خارطة الطريق وحالة المشروع وسجل التغييرات والأدلة ذات الصلة في PR التنفيذية نفسها.  
**القبول:** PR تجريبية بلا كل الملفات المطلوبة تفشل؛ PR كاملة تنجح؛ الاختبارات لا تقلل اشتراطات الحوكمة السابقة.

## R-154 — تعريف حالات العمل
**العمل:** أضف تعريفًا ثابتًا لحالات planned/in_progress/blocked/done/accepted وشرط الدليل لكل حالة؛ أضف حقول الاختبارات المتخطاة/المستبعدة والحدود غير المختبرة.  
**القبول:** لا يوجد بند marked done بلا أدلة مرتبطة بـSHA وبلا اختبار مناسب أو تبرير موثق.
