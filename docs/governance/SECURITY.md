## الوضع الراهن (مُتحقق من الكود)

### المصادقة
- `APIKeyHeader(name="X-API-Key", auto_error=False)` — `server.py:104`.
- `verify_api_key()` مُعرّف (`server.py:107`) **ولم يُستدع في أي جسم دالة**.
- `ENABLE_AUTH = bool(API_KEY)`؛ `AGOS_API_KEY` فارغ افتراضياً → المصادقة معطلة افتراضياً.
- مسارا `register/remove external agent` يفحصان `ENABLE_AUTH` فقط (رفض 401 عند كونها معطلة) — **لا يتحققان من قيمة المفتاح** حتى عند تفعيلها.

### جدول الحماية الفعلية

| المسار | فحص المفتاح فعلياً |
|---|---|
| `POST /api/tasks`، `POST /api/chat` | لا (يُستقبل ولا يُفحص) |
| `POST/DELETE /api/agents/external*` | لا (فحص `ENABLE_AUTH` فقط) |
| مسارات `/civilization/*` | لا (لا تستقبل المفتاح أصلاً) |
| باقي المسارات | لا |

### CORS
- افتراضي `"*"` مع `allow_credentials=True` و`allow_methods` تشمل PUT/DELETE. تحذير يُسجل عند الإقلاع. قابلية الاستغلال الفعلية غير مقيسة.

### Rate limiting
- `@rate_limit` decorator؛ تخزين `request_counts: Dict[str, List[datetime]]` في ذاكرة العملية (غير مشترك بين العمليات/العقد). مفتاح العميل `request.client.host`.

### الأسرار
- `.env.example` يحتوي placeholders فقط. فحص أولي بأنماط مفاتيح شائعة على الملفات المتتبعة لم يُرجع نتائج — **ليس فحصاً شاملاً ولا دليلاً قطعياً**.
- `render.yaml` يستخدم `sync: false` للمتغيرات الحساسة.
- CI يستخدم `secrets.PYPI_API_TOKEN`.
