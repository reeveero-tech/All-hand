## الوضع الراهن (مُتحقق من الكود — محدث بعد R-004 وR-041)

### المصادقة
- `APIKeyHeader(name="X-API-Key", auto_error=False)` مع `verify_api_key()` تفحص قيمة المفتاح (401 عند الغياب، 403 عند الخطأ) — مُفرضة على المسارات الحساسة منذ R-004 (تغطيتها في `tests/test_security.py`).
- `ENABLE_AUTH = bool(API_KEY)`؛ `AGOS_API_KEY` فارغ افتراضياً → وضع مفتوح ما لم يضبط المشغّل المفتاح.
- **جديد R-041**: مدخلا `AGOS_API_KEY` و`AGOS_ALLOWED_ORIGINS` موجودان في `render.yaml` كـ`sync: false` (يدخلهما المشغّل في لوحة Render؛ لا سر في المستودع). ترك المفتاح فارغاً يبقي الوضع المفتوح.

### جدول الحماية الفعلية (بعد R-004)

| المسار | فحص المفتاح فعلياً |
|---|---|
| `POST /api/tasks`، `POST /api/chat` | نعم (`verify_api_key`) |
| `POST/DELETE /api/agents/external*` | نعم (يفحص قيمة المفتاح) |
| مسارات `/civilization/*` | نعم (`verify_api_key` مُمرر إليها) |
| باقي المسارات (health/metrics/قراءة المهام) | لا (مقصود: مسارات فحص عامة) |

### حدود معروفة
- الواجهة `web/` لا ترسل `X-API-Key` (قيد موثق لـ R-043) — تفعيل المصادقة يكسر استدعاءات الواجهة الحالية حتى يُحل.

### CORS
- الافتراضي `AGOS_ALLOWED_ORIGINS` غير مضبوط = `["*"]`، ومعه تُعطّل بيانات الاعتماد (R-004: credentials header معطلة عند `*`؛ تُفعّل فقط مع قائمة صريحة). تحذير يُسجل عند الإقلاع.

### Rate limiting
- `@rate_limit` decorator؛ تخزين `request_counts: Dict[str, List[datetime]]` في ذاكرة العملية (غير مشترك بين العمليات/العقد). مفتاح العميل `request.client.host`.

### الأسرار
- `.env.example` يحتوي placeholders فقط. فحص أولي بأنماط مفاتيح شائعة على الملفات المتتبعة لم يُرجع نتائج — **ليس فحصاً شاملاً ولا دليلاً قطعياً**.
- `render.yaml` يستخدم `sync: false` للمتغيرات الحساسة.
- CI يستخدم `secrets.PYPI_API_TOKEN`.
