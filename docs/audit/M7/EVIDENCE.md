### الفجوة (قبل الإصلاح — سجل `raw/253`)

### بعد الإصلاح (سجل `raw/254`)

المسبار نفسه: المساران يفشلان مغلقين برسالة السياسة الثابتة («blocked non-public address … 127.0.0.2») **قبل أي اتصال TCP** — المستمع الداخلي: صفر وصول.

### الإصلاح

| المسار | الآلية |
|---|---|
| urllib (`safe_urlopen`) | اتصالات `http.client` مقيدة (`_GuardedHTTP(S)Connection`) تحل مرة واحدة، تفحص كل العناوين (`check_resolved`)، وتفتح الـsocket مباشرة إلى sockaddr مفحوص؛ Host وSNI والتحقق من الشهادة على اسم المضيف الأصلي؛ `ProxyHandler({})` يعطّل اكتشاف الوكلاء من البيئة |
| aiohttp (`ExternalAgentAdapter`) | `GuardedResolver` مربوط بـTCPConnector بلا كاش DNS — العناوين المسلَّمة للموصل مفحوصة فقط؛ العناوين الحرفية بلا DNS يغطيها الفحص المبكر |
| مشترك | `check_resolved` (كل العناوين؛ الإجابة المختلطة ترفض جملة؛ الفارغ/المعطوب رفض مغلق) و`vetted_sockaddrs` (حل واحد → فحص → أهداف مفحوصة) |
