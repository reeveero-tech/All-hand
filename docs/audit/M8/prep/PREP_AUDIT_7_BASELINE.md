## القيود والحوادث المسجلة (بصدق كامل)

- **تشغيل أول على Python 3.14.8 ببيئة نظام**: أُجري قبل البيئة النظيفة؛ مطابق في الأعداد لكنه سُجل بوصفه تشغيلًا في بيئة مختلفة (تعارض `jiter/openai` من حزم النظام)، والاستشهاد المعتمد هو تشغيل 3.12.15 النظيف.
- **انتهاء صلاحية اعتمادات GitHub في منتصف الجلسة**: بعد اكتمال الفحوص المحلية وقبل الدفع، بدأ `gh` و`git` عبر الوكيل يعيدان `401 Bad credentials`. استُكمل التحقق للقراءة فقط عبر REST العام غير الموثق (المستودع عام)، وطُلب إعادة التفويض عبر القناة الرسمية. **هذه الدفعة التزام محلي فقط** (`9903e29`) — لا دفع ولا PR ولا دمج ولا CI عليها بعد. لم يُعدَّل شيء على البعيد خلال الانقطاع. هوية مؤلف الالتزام نُقلت من تاريخ المستودع ولم تُتحقق من الحساب المتصل — ستُتحقق قبل الدفع.
- **خطأ تشغيلي محلي (معالج فورًا؛ موثق من reflog)**: أثناء مسبار اختبار الدفع، سُلسلت `git reset --hard HEAD~1` بعد أوامر commit فاشلة فحرّكت main المحلي للخلف عبر عمليتي reset (إلى `1b66141` ثم `e26cf0f`)؛ أُعيد فورًا إلى `origin/main` (`3df8e86`) ولا عمل فُقد. سُجل هنا لأن أمر التسليم يمنع الإخفاء.

3. عند استيفاء Q-028: تُحسم حالة R-169 وPR ‏#219 وفق الحوكمة، عندها يُتاح قرار بدء R-170 وفق ترتيب الخارطة.

- لم تُعدّ خطة تنفيذ لـR-170 — البند لم تُفتح اعتمادياته، والتحضير له خارج نطاق هذه الدفعة بقرار واعٍ.
