## 6. الإيقاف الآلي — كيف يصبح الحد الأعلى صلبًا لا أمنية
1. **TTL داخل العقدة** (الطبقة الصلبة): `InstanceInitiatedShutdownBehavior=terminate` + `shutdown -h +<TTL>` في user-data ⇒ العقدة **تُحذف** (لا تتوقف فقط) عند TTL الجولة (الجدول §4) مهما حدث للمشغل. مع `DeleteOnTermination=true` لأقراص EBS ⇒ لا تبقى أقراص تُفوتر.
2. **إنذار خمول**: إنذار CloudWatch على CPU < 5% لمدة 30 دقيقة بإجراء terminate — يوقف العقد المنسية قبل TTL.
3. **سكربت التشغيل نفسه**: ينهي العقد الثلاث في `finally` بعد تنزيل السجلات.
4. **AWS Budgets**: إنذار عند 50%/80%/100% من السقف — **ليس سقفًا صلبًا** (بيانات الفوترة متأخرة)؛ الطبقة الصلبة هي TTL.
- الحد الأعلى لكل جولة = TTL × $1.522 + نقل خارجي ≤ $0.90 — لا يمكن تجاوزه إلا بإنشاء جولة جديدة (قرار تشغيل جديد).
