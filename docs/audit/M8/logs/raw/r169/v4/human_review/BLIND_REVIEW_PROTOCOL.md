# إجراء المراجعة العمياء ذات المرحلتين — Q-028 / R-169 v4 b1

> **الغرض**: حماية الحكم البشري الأولي من التوجيه بأحكام المصحح أو نتائج الوكيل، دون تغيير القياس أو البيانات أو معايير القبول.
> **حد العزل**: النتائج التفصيلية لا تزال موجودة في الفرع العام؛ لذا فإن هذا الفصل إجرائي وليس عزلًا تقنيًا يمنع الوصول. سلّم للمراجع نسخة المرحلة أ فقط ولا تقدّم روابط الفرع العام بوصفها حزمة معزولة. لا يمكن ضمان تعمية تقنية كاملة في هذا المستودع العام.

## قبل البدء

المراجع يجب أن يكون إنسانًا لم يطوّر المصحح v1–v4 ولم يضبطه، ولم يطّلع مسبقًا على مجموعة test أو أحكامها، وألا يكون الوكيل الذي أنتج الوسوم. إذا لم تتحقق الشروط، فلا تُسجّل المراجعة مستوفية Q-028.

## المرحلة أ — الحكم المستقل، قبل كشف النتائج

**لا تفتح** تقرير `R169_REPORT_V4_B1.md`، أو `reviewer_form.json`، أو ملفات الوسوم، أو JSONL للنتائج، أو الفهرس الأصلي `REVIEWER_CASE_INDEX.md`، أو أي مراجعة سابقة قبل تثبيت أحكام المرحلة أ.

استخدم فقط:
1. [هذا الإجراء](BLIND_REVIEW_PROTOCOL.md).
2. [فهرس المرحلة أ المحايد](REVIEWER_CASE_INDEX_PHASE_A.md).
3. [ورقة الردود baseline](../blind/test_baseline_b1.sheet.md) و[ورقة grounded-v2](../blind/test_grounded-v2_b1.sheet.md).
4. [نموذج الحكم المستقل الفارغ](reviewer_blind_form.json).

لكل حالة، اقرأ السؤال والمصادر والرد ومعيار الحكم في الورقة، وسجّل `pass` أو `fail` أو `uncertain`، مع تعليل وثقة. لا تخمن حكم المصحح، ولا تستخدم هوية مجموعة الحالة كدليل على الحكم.

بعد مراجعة الحالات الـ27، أكمل بياناتك فقط إن كنت مستوفيًا لشروط الاستقلال، ثم سلّم نسخة المرحلة أ إلى المنسق. **يجب تثبيت نسخة كاملة مع وقت استلام قبل فتح المرحلة ب**. احتفظ ببصمة النسخة الأولى ولا تستبدلها. إن تعذر إثبات هذا الترتيب، سجّل الانحراف ولا تصف المراجعة بأنها عمياء كاملة.

## المرحلة ب — المقارنة والتحكيم بعد تثبيت المرحلة أ فقط

بعد حفظ نسخة المرحلة أ ووقت استلامها:
1. افتح النموذج الرسمي `reviewer_form.json` وأكمل الحقول المخصصة للمراجع البشري فقط.
2. افتح التقرير `R169_REPORT_V4_B1.md` والفهرس الأصلي `REVIEWER_CASE_INDEX.md` وأسباب المصحح؛ أكمل `grader_or_label_who_is_right` مع تعليل لكل حالة.
3. لا تعدّل الحكم الأولي بعد الاطلاع على الأحكام السابقة؛ إذا أضافت المرحلة ب تفسيرًا لاحقًا فسجّله منفصلًا.
4. شغّل `python3 scripts/check_q028_form.py path/to/filled_form.json`. تتحقق الأداة من البنية والاكتمال فقط، ولا تقرر صحة الحكم أو أهلية المراجع.

## سلامة البيانات والبوابات

- لا تغيّر الردود الخام أو الوسوم أو FREEZE أو المصحح أو العتبات أو بصمات الحالات.
- لا يملأ أي وكيل أو نموذج أي نموذج مخصص للمراجع نيابة عنه.
- لا تغيّر حالة R-169، ولا تبدأ R-170، ولا تدمج PR #219 لمجرد إكمال المرحلة أ؛ تبقى بوابات الحوكمة ومعايير القبول حاكمة.
- لا تعتبر مجلس المراجعة الاصطناعي بديلًا للمراجع البشري.
