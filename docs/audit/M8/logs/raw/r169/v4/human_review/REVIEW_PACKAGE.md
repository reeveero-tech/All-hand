## المرحلة أ — الحكم المستقل قبل إظهار النتائج

لا تعط المراجع رابط المستودع أو PR #219. صدّر وأرسل له هذه الملفات الأربعة فقط في حزمة مستقلة خارج المستودع:
- [إجراء المراجعة ذات المرحلتين](BLIND_REVIEW_PROTOCOL.md)
- [فهرس المرحلة أ المحايد](REVIEWER_CASE_INDEX_PHASE_A.md)
- [الحالات المختارة بأسماء مستعارة](BLIND_REVIEW_CASES_PHASE_A.md)
- [نموذج الحكم الأولي الفارغ](reviewer_blind_form.json)

لا ترسل خريطة الربط أو الفهرس الأصلي أو التقرير أو النموذج الرسمي أو ملفات الوسوم والنتائج الخام. على المراجع ألا يكون قد طالع هذه المواد قبل تسجيل الحكم. تثبّت نسخة المرحلة أ المؤرخة والمبصمة لدى المنسق قبل الانتقال إلى المرحلة ب.

## المرحلة ب — للمنسق بعد تثبيت المرحلة أ

بعد حفظ النسخة الأولية ووقت استلامها، استخدم [خريطة الربط للمنسق — المرحلة ب فقط](REVIEWER_CASE_MAPPING_PHASE_B.json) لربط Cxx بالحالة الأصلية، ثم افتح [النموذج الرسمي](reviewer_form.json) والتقرير والفهرس الأصلي. لا تسلّم خريطة الربط للمراجع في المرحلة أ. انقل أحكامه الأصلية دون تعديل، وأكمل التحكيم الرسمي بمبرراته. شغّل `python3 scripts/check_q028_form.py path/to/filled_form.json`؛ هذه أداة اكتمال بنيوي لا حكم على صحة المضمون.

## القيود

لا تغيّر الردود الخام أو الوسوم أو FREEZE أو المصحح أو العتبات أو البصمات. هذه الحزمة لا تحقق عزلًا تقنيًا داخل مستودع عام؛ يجب تسليم المرحلة أ كنسخة منفصلة. لا يغيّر هذا الإجراء حالة R-169 أو بواباتها؛ PR #219 يبقى ممنوع الدمج حتى استيفاء Q-028 والحوكمة.
