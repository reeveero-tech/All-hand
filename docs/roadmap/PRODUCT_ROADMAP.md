## المرحلة 3: الملفات والمخرجات والتنفيذ المعزول

- **الهدف:** رفع الملفات، وإنتاج مخرجات (Markdown وCSV وصور رسوم) قابلة للتنزيل، ونقل `run_python` إلى بيئة معزولة.
- **القيد:** العزل الحقيقي (حاوية لكل تنفيذ) قد لا يتاح مجانًا على Render. البديل المجاني: تعطيل `run_python` في الإنتاج، وتشغيله محليًا أو عبر الاستضافة الذاتية.
- **قاعدة البيانات:** جدول `artifacts` وSupabase Storage (الطبقة المجانية 1GB).

## المرحلة 4: سجل الأدوات والموافقات والموصلات والمهارات

- **سجل الأدوات:** خطورة لكل أداة (read / write / external / destructive).
- **حالة `waiting_approval`:** كيان Approval بنطاق محدد.
- **أول موصل حقيقي:** GitHub بتوكن المستخدم عبر OAuth App مجاني.
- **عميل MCP:** عبر HTTP.
- **المهارات:** محمّل `SKILL.md` بالصيغة المتوافقة مع Agent Skills.

## المرحلة 5: المشاريع والذاكرة المنظمة

## المرحلة 6: المتصفح المعزول

Playwright في حاوية، ولقطة لكل خطوة، وتسليم يدوي لتسجيل الدخول. يحتاج موارد قد لا تتوفر مجانًا، فيلزم قرار المالك.
